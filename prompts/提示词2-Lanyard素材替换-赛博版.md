# 提示词 2 · 替换 Lanyard 视觉素材（赛博风格版）

> 用途：把当前 React Bits Lanyard 组件里的默认视觉素材，替换成我提供的新素材，**保持原组件的 3D 结构与物理交互完全不变**。
> 本版在原有要求上补充了**梦逍遥赛博风格基准**（第三节），确保替换后的工牌与整站质感一致。
> 新素材目录：`【待填：新素材实际路径，建议放 app/src/components/lanyard/ 下】`
> 现有素材：`app/src/components/lanyard/card.glb`（工牌模型）、`lanyard.png`（挂绳纹理）

---

## 一、任务

请把当前 React Bits Lanyard 组件中的默认视觉素材替换成我提供的新素材，并尽量保持原组件的 3D 结构、物理效果和交互逻辑不变。

先检查当前 Lanyard 组件使用的模型、纹理、材质、UV、资源路径以及图片尺寸，再根据我提供的新素材自动判断哪些区域适合于吊带、连接件、卡片正面、卡片背面、Logo、装饰图案或其他视觉纹理。

如果我提供的是一张合成图，请自动识别并拆分需要使用的视觉区域，整理成组件实际需要的独立图片资源；如有纯色背景、黑底或白底，根据实际使用场景处理为透明 PNG 或适合 WebGL / Three.js 使用的纹理格式。

## 二、铁律：只改视觉，不动逻辑

替换过程中只修改视觉素材，**不要随意修改 React Bits Lanyard 原有的**：拖拽、物理摆动、回弹、绳子模拟、重力、鼠标交互、Canvas、相机、灯光和动画逻辑。

如果当前素材替换不需要修改模型结构，就**不要重新建模或重写组件**。

**保持新素材原本的设计内容、比例、颜色、字体、人物、Logo、图案和排版**，不要自行重新设计、重绘、生成或改变主要视觉内容。

> 当前项目已对官方组件做过扩展（`frontImage` / `backImage` / `imageFit` / `lanyardImage` / `lanyardWidth` 这几个 props，通过 canvas 合成写进卡片纹理图集，正面取左半、背面取右半，等比不拉伸）。
> **替换素材时优先复用这些现成入口**，不要另起一套加载逻辑。
> 组件位于 `app/src/components/lanyard/Lanyard.tsx`，调用处在 `app/src/sections/PersonalCard.tsx`，现有调用为 `<Lanyard position={[0, 0, 30]} gravity={[0, -40, 0]} fov={20} transparent />` —— 传素材走上面那几个 props 即可，**不要改动这行已有的物理参数**。

## 三、梦逍遥赛博风格基准（素材必须与整站一致）

> 本站视觉系统取自 `css/style.css` 的 `:root` 与 `portfolio/index.html`。工牌作为页面的一个视觉单元，配色与质感必须统一。

### 3.1 色彩令牌

| 用途 | 变量 | 色值 |
|---|---|---|
| 页面底色 | `--bg` | `#04060d` |
| 次级底色 | `--bg-2` | `#070b16` |
| 面板 / 卡片底 | `--panel` | `rgba(8,13,27,.94)` |
| 主色 · 青 | `--cyan` | `#00e5ff` |
| 强调 · 洋红 | `--pink` | `#ff2a6d` |
| 次强调 · 紫 | `--purple` | `#a855f7` |
| 点缀 · 黄 | `--yellow` | `#fde047` |
| 状态 · 绿 | `--green` | `#38f2a1` |
| 正文 | `--text` | `#dbe7ff` |
| 次要文字 | `--dim` | `#8fa0c9` |
| 描边 | `--line` | `rgba(0,229,255,.28)` |

### 3.2 风格规则

- **若新素材本身就是成品赛博风设计图**：原样使用，**不重绘、不改配色、不改排版**，只做 UV / 比例 / 透明适配；
- **若素材需要补底、描边、分区或扩展**：只用上面的色板 —— 青 `#00e5ff` 主色、洋红 `#ff2a6d` 点睛、紫 `#a855f7` 次级；深色底用 `#04060d` / `#070b16`（`app/` 版区块实底为 `#050a12`，同色系）；**禁止引入暖琥珀 / 橙黄 / 衬线字体那套模板原始风格**；
- **一律直角，无圆角**；边框用 `--line` 青描边 + 青色辉光，禁止毛玻璃与柔和投影；
- 字体只用 **GeistMono**（等宽），英文大写 + 宽字距；**禁止外部 CDN 字体**；
- 工牌与页面其他部分质感一致：扫描线、细网格、霓虹辉光、故障色散（青 / 洋红）可用。

## 四、UV 与纹理映射检查

根据当前 3D 模型的 UV 自动调整纹理映射，确保图片在模型上显示正确。**重点检查：**

- 是否出现拉伸或压缩；
- 是否上下左右颠倒；
- 是否镜像；
- 是否裁切主要内容；
- 是否比例失真；
- 是否存在明显重复接缝；
- 是否存在纹理错位；
- 是否有透明边缘或黑边；
- Logo、人物和文字方向是否正确。

如果新素材与原模型比例不同，优先通过**纹理映射、UV、repeat、offset、rotation、cover / contain 逻辑或模型显示比例**进行适配，**不要直接把图片强行拉伸到原尺寸**。

## 五、透明与材质

如果素材包含透明区域，请正确处理 `alpha`、`transparent`、`alphaTest`、`depthWrite` 等材质参数，避免出现黑底、白边、透明排序错误或边缘发灰。

> 赛博风素材多为深色底，抠图时要特别小心：深色主体 + 深色底容易留下黑边或灰边，建议用 `alphaTest` + 边缘羽化处理，并确认在 `#04060d` / `#050a12` 页面上不出现可见方形底。

## 六、正反面绑定

如果工牌正反面使用不同素材，请分别正确绑定；如果只有正面素材，则保留原来的背面逻辑，除非新素材中明确提供了背面设计。

## 七、吊带纹理

吊带纹理需要沿吊带方向自然延展，如果需要重复纹理，请保证 `repeat` 和 UV 方向合理，避免 Logo 被压扁、倒置、过度重复或产生明显拼接。

## 八、清晰度

新素材尽量保持清晰，避免因为 texture filtering、尺寸缩放或压缩导致模糊。根据当前 Three.js 设置合理处理 `texture colorSpace`、`anisotropy`、`minFilter`、`magFilter` 和 `mipmap`，保证视觉质量。

## 九、资源与路径

同时正确更新 public / assets 中的资源文件与引用路径，**不要保留无用的旧素材引用**。检查所有图片和模型资源是否正常加载，不允许出现 404、路径错误、纹理丢失或控制台报错。

## 十、边界

**不要修改页面其他内容**，包括背景、导航、文字、布局、滚动、hover、响应式结构和其他动画效果，**只处理 Lanyard 组件内部需要替换的视觉素材**。

## 十一、执行与修复

直接在当前项目中完成替换，运行项目检查最终效果，并根据实际显示结果自动修复纹理方向、UV、透明、比例、位置和资源路径问题。

## 十二、最终效果要求

新素材**完整、清晰、比例正确**，能自然贴合当前 Lanyard 3D 模型，同时**保留原组件已有的真实拖拽、摆动和物理效果**，并且与整站赛博风格在配色与质感上完全统一。

替换完成后请在 `app/` 下执行 `npm run build` 验证构建通过。
